# Contributing / 提交资料

Share a paper, project or correction through an [Issue](https://github.com/dongtsi/awesome-trustworthy-jev/issues/new/choose) or [Pull Request](https://github.com/dongtsi/awesome-trustworthy-jev/compare).

**[Agent guide](AGENTS.md) · [Catalog](data/catalog.json) · [Taxonomy](data/taxonomy.json) · [Datasets](data/datasets.json)**

Edit the source data, not the generated README, HTML, RSS or charts. The maintainer validates your changes and regenerates those views together. No installation is needed.

For additions, follow the [record instructions](AGENTS.md#contribute-data), or add `submissions/<short-name>.md`:

```text
Title:
Type: Paper / Project / Article / Official
Original URL:
First publication date:
Authors / repository owner:
Category:
Summary: method and finding in one or two sentences
Datasets / code links:
Duplicate check:
Unknown or unverified fields:
```

Use original sources, check for duplicates, and do not upload PDFs. Contributions follow the [content](LICENSE) and [code](LICENSE-CODE) licenses; identify third-party material.

---

欢迎通过 Issue 或 PR 提交论文、项目和勘误。

**[AI 贡献指南](AGENTS.md) · [目录数据](data/catalog.json) · [分类](data/taxonomy.json) · [数据集](data/datasets.json)**

修改数据即可，README、HTML、RSS 和图表由维护者校验后统一生成，不用安装环境。可以让 AI 先读贡献指南，再按现有结构修改相关数据；不确定的资料请新增 `submissions/<简称>.md`，按上面的格式填写并标明待核实项。

先查重，使用原始来源，不上传 PDF。贡献遵循仓库许可，第三方材料请注明来源。
